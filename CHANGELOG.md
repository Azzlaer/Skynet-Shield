# Changelog

## 0.6.0-alpha (proposed)
- Server-side diagnostic timing regularity analyzer with configurable policy.
- Synthetic tests for regular, variable, short, batched and invalid samples.
- No keyboard hooks or automatic sanctions; live calibration and integration pending.

## 0.5.0-alpha (proposed)
- Native HTTPS heartbeat via WinHTTP.
- Reference session validator with expiration, revocation and atomic replay rejection.
- Native argument validation and Python session tests.
- Live service, GameServer binding and integration testing pending.

## 0.4.0-alpha
- Current-process module inventory and diagnostic path classification.
- Windows CTest coverage for enumeration and path matching.
- No external scanning or enforcement.

## 0.3.0-alpha
- Windows CNG SHA-256 buffer verification API in native DLL.
- Known-answer and negative tests for caller-owned buffers.
- Runtime integration and trusted baseline provisioning pending.

## 0.2.0-alpha
- Offline SHA-256 integrity manifest generation and signature verification via OpenSSL.
- Negative tests and CI for Win32/x64 foundation builds.
- Native DLL integration pending.

## 0.1.0-alpha
- C++17 DLL foundation and explicit lifecycle API.
- CMake build and smoke test.
- Architecture and security documentation.
