# Changelog

## 1.0.0-alpha (proposed)
- Windows x86/x64 SDK distribution, framework-dependent AdminCP and server tools.
- Allowlisted ZIP packaging, SHA-256 manifests, CI artifacts and Spanish lab installation guide.
- Not production ready; real MU integration remains pending.

## 0.13.0-alpha
- Strict API parsing, removed-instance grant cleanup, expiry locking and registry validation.
- Concurrent replay/rotation and loopback lifecycle regression tests.
- Targeted security review and release gates.

## 0.12.0-alpha
- AdminCP multi-server and session views, filtered export and XML registry validation.
- Read-only administrative session endpoint with bounded results and no secrets.
- Diagnostic tabs for integrity, timing reports and local database size.

## 0.11.0-alpha
- XML registry with separate GameServer credentials, scoped sessions and event attribution.
- Admin server overview and SQLite migration; isolation tests.

## 0.10.0-alpha
- Native Windows ShieldBridge DLL with versioned C ABI, session issue and revoke over HTTPS.
- Input validation tests and integration contract; actual host and multi-server support pending.

## 0.9.0-alpha
- Source-level client heartbeat worker and GameServer HTTPS reference adapter.
- Lifecycle tests and MU integration guide.
- Actual MU source integration, event transmission and end-to-end TLS pending.
